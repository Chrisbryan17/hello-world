# Temporary CollapseCAD Native FreeCAD Execution Mirror

This isolated branch exists only to run the native FreeCAD generator from the private `Chrisbryan17/Webots` engineering branch. The compressed payload is checksum-gated. The workflow generates, reopens, validates, and uploads nine `.FCStd` development documents.

The output is not ISO/CSC certification evidence and the branch is not the engineering source of truth.
